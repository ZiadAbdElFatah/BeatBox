# BeatBox

BeatBox is a simple Java-based collaborative drum machine that allows users to create beats and share them in real-time over a network.

## Features 
-  **16-track sequencer** with multiple instruments.
-  **MIDI playback** to generate beats.
-  **Network connectivity** to share beats with others.
-  **Adjustable tempo** with speed control.
-  **Send and receive beat patterns** in real-time.
-  **Random pattern generation** to create unique beats instantly.
-   **Pre-saved patterns** for styles like Jazz, Rock, and more.



## How It Works 
1. Start the **MusicServer** (`MusicServer.java`) to allow connections.
2. Launch the **BeatBox** client (`BeatBox.java`) and connect to the server.
3. Use the GUI to:
   - Select instruments and toggle beats.
   - Start and stop playback.
   - Adjust tempo.
   - Send your beat patterns to the server.
   - Click a button to **generate random beat patterns**.
   - Choose from **pre-saved patterns** like Jazz, Rock, and more.
4. Other connected users can receive and play your beat sequences in real-time!
